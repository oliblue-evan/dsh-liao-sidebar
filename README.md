# 侧栏管家

侧栏管家帮助整理 DeepSeek Harness 的侧栏入口：除「插件」外，其他入口都可以收进「更多」，并可拖动排序、设置快捷键或添加自定义网页链接。自定义链接与侧栏入口共用「更多」中的排序，也可以从设置页上下调整。

DSH `0.2.2-rc.3` 起侧栏自带官方「更多」入口，侧栏管家会直接复用这个按钮和菜单，不再额外生造第二个「更多」：收纳的入口与自定义链接排在官方菜单上方，「浏览更多插件」「创建你的插件」仍保留在菜单下方。旧版宿主没有官方入口时，仍会自动回退到原有的自绘按钮。

官方菜单里已经渲染的未固定入口会直接使用官方行和「固定到左侧栏」按钮。点击官方 Pin / Unpin 会同步侧栏管家的收纳状态。

点击「更多」会把收纳项原地展开在侧栏里。切换页面后列表保持展开，再点「收起」关闭。默认也支持悬停打开右侧浮菜单，窗口空间不足时会调整位置。聚焦「更多」后按 `↓` 可打开宿主菜单，按 `Esc` 关闭浮菜单。固定项显示在「更多」上方，取消固定后追加到收纳列表末尾，也可以直接拖到指定位置。

设置可在插件详情页的「侧栏管家设置」中调整。侧栏入口与自定义链接共用一条统一排序列表，可以直接跨类型上下移动，并逐项查看「侧栏显示／收在更多」状态、设置快捷键；自定义链接卡只负责添加新链接。窄屏会自动切换为单列布局。改动立即生效并保存在当前设备。首次与「插件书架」同时使用时，会导入书架中已有的侧栏顺序、收起项、快捷键和链接偏好；插件书架的其他功能与设置保持独立。

当前页面位于「更多」内时，默认由「更多」右侧的图标提示。开启「在侧栏显示当前收纳入口」后，当前入口也会以独立按钮显示在「更多」上方，直到切换页面。暂时被停用或重载的插件入口会保留原有位置和收起状态，恢复后不会跳回默认顺序。快捷键不能重复绑定，也会检测 DSH 宿主通过 `aria-keyshortcuts` 声明的组合；已保存的宿主冲突会让宿主优先并在设置页提示；最多可设置 100 个快捷键和 30 个自定义链接。

侧栏收起后，悬停「打开侧边栏」会从窗口左侧滑出一条全高侧栏，主内容保持收起时的位置和宽度。鼠标离开后侧栏滑回，点击打开侧栏按钮可固定为正常侧栏。设置页可关闭预览，浮层里也可用 `Escape` 逐层关闭。

自定义链接支持编辑和选择打开位置。DSH 内置浏览器需要有可用会话，无法打开时回退到系统浏览器。仅 Web 可以选择在当前网页打开。设置页的「配置备份」支持导出 JSON、粘贴导入和恢复默认。

从 DSH `0.2.2-rc.1` 起，macOS Desktop 只自动排除显式声明的窗口拖拽区域。浮层、标题栏按钮克隆和「更多」菜单会声明 `data-window-drag-exclude`，在覆盖标题栏时仍可正常点击，不会变成拖动窗口。

设置页的「显示适配」会自动识别：侧栏收起后，当前页面的标题或控件是否进入了 macOS 窗口顶部的安全区。需要补偿的页面会参考官方入口页的留白规则，临时补齐顶部 `28px + 窗口安全区`、左右 `clamp(24px, 4vw, 48px)` 和底部 `48px`；浮层预览时保持同一留白，浮层本身仍使用原来的左上角锚点。侧栏展开或切换到已适配的页面时立即还原。总开关控制自动识别，每个侧栏入口也有独立的「优化」开关，并显示「需优化 / 已优化 / 已适配」状态。识别依据页面实际布局，不维护第三方插件名单。

## 安装

```sh
dsh plugin --profile desktop add github:oliblue-evan/dsh-liao-sidebar
```

也可以把 `https://raw.githubusercontent.com/oliblue-evan/dsh-plugin-index/main/index.json` 添加为 DSH 的自定义插件索引源。

## 开发与检查

```sh
pnpm install
pnpm check
pnpm test
pnpm pack:check
```

`pnpm test` 包含单元测试和使用本机 Chrome 的拖拽交互测试；没有 Chrome 时，浏览器测试会明确跳过。`pnpm pack:check` 另外验证打包产物能通过真实 DSH ClientModuleSystem 加载。

已验证的宿主版本见 `package.json` 中的 `dsh.compatibility.dshReleases`。
